给客户的操作指引（20260930c 版包）—— 直接照着做
=========================================================
【当前进度】上一轮已经把「黑屏 + 设备管理器代码 43」解决了（GSP 已启用、快速启动已关、设备状态＝这个设备运转正常）。
            现在只剩 **PCIe Gen2（链路速率）** 没落地：原因是这张卡的 VBIOS 是 90.06.67.00.06，
            我们原来只按 90.06.67.00.04 的寄存器基线写死判断，两边（EFI 和 Windows 工具）都因为“基线不认识”主动放弃了写入。
            新版已改成“按位判定”，并加了 GPU 侧重训兜底 + 服务启动类型自动纠正。

第 1 步：用新版包跑一次修复（会立刻执行一遍开机任务，把 Gen2 目标值写进去）
  把 40hx-oneclick-20260930c 整个文件夹放到桌面，管理员 PowerShell：
    powershell -ExecutionPolicy Bypass -File "C:\Users\Administrator\Desktop\40hx-oneclick-20260930c\Install-40HXUnlock.ps1" -Mode Repair -RunNow
  结束前会打印任务结果 rc（0x0 = 好）与 postbind 末尾几行。

第 2 步：核对 Gen2 有没有落地（不用重启）
  1) 管理员 PowerShell：
     powershell -ExecutionPolicy Bypass -File "C:\Users\Administrator\Desktop\40hx-oneclick-20260930c\Install-40HXUnlock.ps1" -Mode Verify
     期望：算力解锁 PASS、`PCIe Gen2: PASS (physical Gen2 x16)`、GSP PASS、40HX 设备 OK
  2) 看 %ProgramData%\CMP40HXGen2\windows\logs\retrain-inpout.log 末尾：
     要看到 `GPU final : Gen2 x16 LNKSTA=0x1102` 与 `ROOT final: Gen2 x16 LNKSTA=0xF102`
  3) 双击 状态自检.bat，看到"全绿 -- WDDM + PCIe Gen2 + 算力满血"

第 3 步：如果第 2 步还是 Gen2 FAIL / 任务 rc 不是 0
  把这两个日志文件发回来（整个文件夹更好）：
    %ProgramData%\CMP40HXGen2\windows\logs\retrain-inpout.log
    %ProgramData%\CMP40HXGen2\windows\logs\postbind.log
  或者直接双击 40hx-oneclick-20260930c\诊断包-20260930\一键诊断.cmd，把桌面出的报告 + zip 发回来
  （新版报告里已经会自动带上 VBIOS、基线判定、EFI 有没有 abort、服务状态这些关键行）。

第 4 步：完全关机再开机一次（把状态固化）
  开始菜单 → 关机，最好拔电 10 秒。开机后任务会自动再跑一遍，届时再 `-Mode Verify` 一次即可。

附：回滚（任何时候都能退回没解锁的状态）
  powershell -ExecutionPolicy Bypass -File "<包目录>\Install-40HXUnlock.ps1" -Mode Uninstall -Yes
