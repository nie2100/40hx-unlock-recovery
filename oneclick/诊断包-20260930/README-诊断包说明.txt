CMP 40HX —— "装完重启黑屏 / 设备管理器代码 43" 诊断采集包（2026-09-30）
============================================================
怎么用（就一步）
  1) 把整个文件夹拷到出问题的电脑上（不要只拷一个文件）
  2) 双击  一键诊断.cmd   → 弹 UAC 点"是" → 等 1~3 分钟
  3) 桌面会出现三样东西，一起发回来（微信直接发 zip 最方便）：
       40HX诊断报告-<机器名>-<时间>.txt        ← 主体报告，记事本能直接看
       40HX诊断-<时间>.zip                     ← 原始日志（ESP 日志 / postbind.log 等）
       40HX诊断-<时间>\                        ← 同上，文件夹形式

它做什么（全程只读，放心跑）
  · 读显卡/显示设备状态、代码 43、驱动版本、PCIe 位置
  · 读 GSP 固件状态 + EnableGpuFirmware 注册表（解锁后驱动认不认卡的关键）
  · 读 nvidia-smi 原文（含报错段）
  · 读一键包自己的日志：postbind.log / retrain-inpout.log / last.log / ace-state.json
  · 读 ESP 上的 40hx_log.txt（解锁固件日志）与两个 EFI 的哈希
  · 读固件启动项（BootOrder / Boot#### / BootNext）
  · 读最近 3 天开机相关事件（含开机耗时、任务计划、驱动报错）→ 定位黑屏窗口
  · 把上面这些原样拷一份到桌面文件夹里

它不做什么
  · 不改注册表、不写 EFI/NVRAM、不创建或启动任何驱动/服务
  · 不停/起反作弊（ACE）、不动系统设置 —— 跑完机器和跑之前完全一样

★ 修复工具：修复-GSP.cmd（看报告的第 0 节再决定要不要跑）
  只有当报告里 [判据 A] 写着"GSP 未启用（显示 N/A）"时才跑它。
  它只写一个注册表值（40HX 显示类子键的 EnableGpuFirmware=1），可逆，会打印还原命令。
  跑完必须【完全关机】（开始菜单→关机；不是"重启"），最好拔电 10 秒，再开机。
  然后重跑 一键诊断.cmd 复核 [判据 A] 是否变成版本号。
  为什么：GSP 没开时，解锁固件把算力解开后驱动认不了这张卡 → 黑屏一段时间 + 代码 43。

报告最后有"待客户回答"6 问，麻烦顺手补一下（这几条决定下一步怎么修）：
  Q1 显示器插在哪块卡上（主板核显 / 另一张独显 / 40HX 改装输出）
  Q2 黑屏出现在哪个阶段（BIOS logo 后一直黑 / Windows 转圈时黑 / 该出桌面时黑）
  Q3 完全关机（断电）再开，黑屏和 43 会消失吗
  Q4 装本包之前装过厂商版解锁工具或超频工具吗
  Q5 40HX 插在第几个 PCIe 槽
  Q6 设备管理器里 40HX 属性→常规 里的"设备状态"原文

只想手动跑也行（管理员 PowerShell）：
  powershell -ExecutionPolicy Bypass -File .\40HX诊断.ps1
