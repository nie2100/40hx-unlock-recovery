ACE 弹窗 / 腾讯游戏进不去 —— 在那台机器上怎么查（先读我）
======================================================

这是什么
  一个只读采集器（ACE-Diag.ps1）：把"这台机器的 ACE 状态 + 一键包的运行证据"一次性抓成一份报告。
  采集完把报告整份发回，就能定性，不用猜。

怎么用
  1. 把本文件夹（或解压出来的文件夹）拷到出问题的那台电脑上：U盘 / 微信 / QQ 都行，别放安装目录里。
  2. 双击  排查ACE.cmd  → UAC 点"是" → 约 20 秒。
  3. 桌面上会出现  ACE排查报告-<计算机名>-<时间>.txt  → 整份发回。
     报告最后一节"结论与建议"里有判定；就算没命中任何判据，也把原样发回，我按原始证据继续判。
  4. 如果允许远程（向日葵/ToDesk/微信指挥），也可以让他在管理员 cmd 里跑：排查ACE.cmd -Fix

-Fix 只做三件事（不动游戏、不删文件、不碰反作弊安装目录）：
  · ACE-BOOT 启动类型若是 Disabled → 改回 System（原本就是 System 的才改）
  · ACE-BOOT 没在运行 → sc start 拉起来
  · ACE 托盘进程若不在用户会话 → 重启托盘（"反作弊初始化失败"时一下就见效）

为什么与一键包有关：现在有两代路径，报告第 5b 节能区分
  · 老路径：为了落地 PCIe Gen2，会在开机后十几秒里**临时停掉腾讯 ACE-BOOT** → 那一轮开机里
    ACE 认为"预启动模式没在启动阶段加载"，游戏就要求"重新安装并重启电脑"；
    若这个停窗撞上登录时由注册表 Run 拉起的 ACE 托盘，还会弹"反作弊初始化失败"。
  · 新路径（2026-09-29 起）：用 inpoutx64.sys 直接写 GPU 寄存器，**全程不停 ACE-BOOT**
    （日志里有  PASS: Gen2 reached on the new path - ACE-BOOT was never stopped）。

怎么读结论（看第 5b 节）
  A) 有新路径 PASS 且"回落老路径 0 次" → 这台机器已经不吃老路径的亏。游戏再报错就不是本包引起的，
     按第 9 节通用项查：ACE-BOOT 被禁用 / 杀软与 ACE 冲突 / ACE 组件缺失 / 浏览器或游戏组件版本。
  B) "新路径成功 0 次" 或 "回落老路径 N 次" → 就是老路径在起作用，客户看到的"要求重启"由此而来。
     根治：升级到新版包（含 40hx-retrain-inpout.ps1 + inpoutx64.sys），跑一次 -Mode Repair，重启一次。
  C) 报告第 4 节显示托盘启动时刻正落在"停 ACE-BOOT ~ 恢复"窗口里 → 托盘竞态（初始化失败）。
     用带自愈的新版 ACE-Toggle.ps1（HealTray）覆盖后跑一次 Repair；急用就先 -Fix 或重启一次电脑。

报告里最有价值的是第 2 / 3 / 4 / 5b / 6 / 8 节：
  开机任务的状态与退出码、ACE 各服务的启动类型、ACE-BOOT.sys 的版本与大小、
  托盘在哪个会话何时启动、日志时间线、事件日志、ACE 安装目录文件清单。

命令行速查（管理员 PowerShell，手边没采集器时用）
  sc.exe query ACE-BOOT ; sc.exe qc ACE-BOOT                       # 在不在跑 / 启动类型是不是 SYSTEM_START
  Get-CimInstance Win32_Process | ? { $_.ExecutablePath -match 'AntiCheatExpert' } |
    select Name,ProcessId,SessionId,CreationDate,ExecutablePath    # 托盘在哪个会话、何时启动
  Get-ScheduledTaskInfo -TaskName 'CMP40HX Gen2 PostBind'          # rc=0 才对
  Get-Content "$env:ProgramData\CMP40HXGen2\windows\logs\postbind.log" -Encoding Default | select -last 25
  Get-Content "$env:ProgramData\CMP40HXGen2\windows\logs\retrain-inpout.log" -Encoding Default | select -last 25

一页判据
  · sc query ACE-BOOT 不是 RUNNING                          → 被停且没恢复：sc start ACE-BOOT，然后重启一次
  · sc qc ACE-BOOT 的 START_TYPE 是 DISABLED                → 被禁用：sc config ACE-BOOT start= system，重启
  · 托盘 SessionId = 0                                      → 跑在系统会话（桌面看不到图标），要重启托盘
  · 开机任务 rc ≠ 0                                         → Gen2 没落地；ACE 只是被顺带停了，看日志尾部
  · 第 5b 节：回落老路径 > 0                                → 用新版包 Repair（见上面 B）
  · ACE 目录为空 / 没有 AntiCheatExpert                     → 与一键包无关：ACE 装坏了，开一次腾讯游戏让它自修

本机（已跑通的同款环境）长什么样，可作对照
  ACE-BOOT         start=System(系统)   state=RUNNING
  ACE-BOOT.sys     2020016 B   FileVersion=1.0.2606.17242
  ACE-Tray.exe     session=1（用户会话，登录时由 Run 拉起，全程不被动）
  开机任务 rc=0x0，postbind.log 尾部：PASS: Gen2 reached on the new path - ACE-BOOT was never stopped

（采集器只读；-Fix 的三个动作会写日志在第 10 节，跑完把报告发回即可。）
