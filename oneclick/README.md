# CMP 40HX 一键解锁 —— 算力满血 + PCIe Gen2 x16

> **结论先放这儿：双击 `一键安装.cmd` → 完全关机再开机 → 双击 `状态自检.bat`，屏幕出现"全绿"就完事了。**
> 全程不用敲命令、不用联网、不用厂商安装器。

---

## 这是什么

CMP 40HX 是矿卡：出厂被人为压了算力（寄存器 SS0 锁住），PCIe 链路也压到 Gen1。
这个包做的事就两件：

1. **解锁算力**（SS0 = 0x88888888，FP32 从 ~1.9 TFLOPs 回到 ~8.35 TFLOPs）
2. **把 PCIe 拉到 Gen2 x16**（双向量测带宽 ~6 GB/s，Gen1 只有 ~3.4 GB/s）

而且这两件事**每次开机自动保持**（开机时固件写寄存器 + 开机任务重训链路），你不用天天点。

## 三步（真的只有三步）

1. **把这个文件夹整个拷到那台装 40HX 的电脑上**（U 盘 / 网络都行），文件夹放在哪都行（例如 `D:\40hx-oneclick`）
2. **双击 `一键安装.cmd`** → 回车 → 等它自己跑完（首次约 1 分钟；它会自己弹管理员授权）
3. **完全关机再开机**（开始菜单 → 关机，**不是"重启"**，最好拔电 10 秒）
   开机后**双击 `状态自检.bat`** → 看到 `全绿 -- WDDM + PCIe Gen2 + 算力满血` = 成功

> ⚠️ **为什么必须"关机"不能"重启"**：解锁由每次开机的固件写显卡寄存器实现，"重启"清不掉显卡残留状态；
> 残留状态不对就会表现成"开机黑屏一会儿 + 设备管理器里 40HX 提示**代码 43**"。

## 正常现象（遇到别慌，不是坏了）

- 火绒/360 弹一次 `Exploit/Vulndriver.ad`：**预期**（这三个驱动都是内核级 BYOVD 工具），弹窗里选"信任"即可；被删了开机任务也会自动补回来（信任区怎么加见 `文档\使用说明-详细.md` 第 1.1 节）
- 安装时弹 UAC + 闪一个黑窗口：正常，装完按任意键关闭
- 装完第一次开机比平时慢几秒：先跑解锁固件、再回到 Windows，正常
- **状态正常时不会再有"下一步-重启后看这里.txt"**（2026-10-02 起：只在"真有失败/还没验证过"时才生成，正常了自动清掉）
- **日志不会无限长大**：包内 `logs\` 只保留最近 10 份；机器上 `C:\ProgramData\CMP40HXGen2\windows\logs\postbind.log` 超过 64 KB 自动裁剪，`retrain-last.log` 每次开机覆盖；**只有失败那次**会另存到 `logs\failures\`（留证据用）

## 出问题怎么办（按现象找工具）

- **Gen2 到不了（一键修复Gen2 最后是 [!!]）**：先看它打印的"体检缺口"。缺口不为"无" = 解锁固件的 Gen2 预埋没写进去 →
  ① 重跑 `一键安装.cmd` → **完全关机**再开机 → 再跑一次；② 还在 → 双击 `工具-测试与修复\补写Gen2预埋.cmd`（先试跑给你看，再补写，可回滚）。
  **2026-10-05 起**：对"解锁固件的基线门禁把这批卡拦掉了"的机器（ESP 日志里 `[efi-b] abort: baseline mismatch`），
  开机任务会**每次开机自动补写**（新路径带 `-AllowPrime`；实测 XVE_OVR 0→6 后 VSEC/LNKCAP/LNKCAP2/TLS 会自己到位，链路 Gen2 x16），
  寄存器易失所以必须每开机一次；健康机器上**补写分支**不写任何字节（重训本身仍会写根端口的 LNKCTL 目标速率位，这是本包原本就有的行为）。关掉它：**以管理员身份**创建空文件 `C:\ProgramData\CMP40HXGen2\NO_PRIME`（那个目录有 ACL 加固，普通另存会失败）；关掉后的那一次开机会走老路径（ACE 停一下再恢复）。注意：**完全关机不会持久关掉补写**——寄存器只是复位，若没有 NO_PRIME，下次开机又会补写。


| 现象 | 去做 |
|---|---|
| 装完重启黑屏 1~2 分钟 / 设备管理器 40HX 代码 43 | 先双击包根 `GSP体检.cmd`（只读；直接告诉你 GSP 卡在哪一步，`/fix` 才会写开关） |
| ↑ 同上（自动的那一步） | 安装器（Install/Repair）**发现 GSP 没启用时会自动跑一次只读体检**，报告落桌面 `40HX-GSP体检-<机器名>-<时间戳>.txt`（包内 `logs\` 也留一份）；只读、不影响安装结论。已启用则跳过（保持安静） |
| 想知道"现在到底解锁没有" | 双击 `状态自检.bat`；或 `-Mode Verify` |
| 手动再修一次 Gen2（不用重启） | 双击 `一键修复Gen2.cmd` |
| 登录后没有桌面 / explorer 不加载 | `工具-测试与修复\桌面恢复.cmd`（没桌面也能跑：任务管理器 → 运行新任务） |
| 腾讯 ACE 报错 / 游戏要"重启修复" | `工具-测试与修复\ACE修复.cmd`（先只读体检，`/fix` 才动手）；注意 `修复ACE.cmd` = 带 `/fix`（**会改系统**），名字只差字序 |

## 装之前只有几件事要确认（脚本也会自己体检）

| 项 | 要求 |
|---|---|
| 引导 | **UEFI + GPT**（MBR 盘要先 `mbr2gpt`） |
| Secure Boot | **关** |
| BIOS | 见下面这张 **BIOS 必改 5 项** 表（头号失败原因是 Above 4G Decoding 没开） |
| BitLocker | 关或已暂停（否则改引导链会索要恢复密钥） |
| NVIDIA 驱动 | 已装（GSP 固件要开着；没开脚本会帮你写开关，然后必须**完全关机**才生效） |
| 杀软 | 火绒/360 加信任区 + 关"启动项保护"（见 `文档\使用说明-详细.md` 第 1.1 节） |

**BIOS 里必须改的 5 项（脚本替你做不了，现场失败绝大多数栽在这里）**：

| # | 改什么（常见叫法） | 设成 | 不改会怎样 |
|---|---|---|---|
| 1 | **Above 4G Decoding**（4G 以上解码） | **Enabled** | **头号失败原因**：8 GB 显存要落在 4 GB 以上地址空间；关着 → 认不到卡 / 代码 43 / 黑屏 |
| 2 | **CSM**（Launch CSM / CSM Support） | **Disabled** | 变成 Legacy 引导 → 判定"固件不是 UEFI 模式"直接中止（前提不满足） |
| 3 | **Secure Boot**（安全启动） | **Disabled**（老华硕选 `Other OS`） | 解锁固件未签名，开着就不执行 → 算力一直没解锁 |
| 4 | **Fast Boot**（快速启动） | **Disabled** | 与 Windows 快速启动叠加成"混合关机" → GSP/驱动改动不生效（代码 43 根因之一） |
| 5 | 该 x16 槽的 **PCIe 速率** | **Auto**（别锁 Gen1） | 锁 Gen1 就永远上不了 Gen2 x16 |

位置（各家叫法不同，按关键词找）：华硕 `Advanced → System Agent (SA) Configuration`、技嘉 `Settings → IO Ports`、
微星 `Settings → Advanced → PCI Subsystem Settings`、华擎 `Advanced → Chipset Configuration`；
CSM / Secure Boot / Fast Boot 都在 `Boot` / `Security` 页。逐条报错对照见 `排查指引.md` 第 3 节。

想先只看不改：`Install-40HXUnlock.ps1 -Mode Check`（纯体检，0 项失败即环境 OK）。

## 想卸载 / 回到没解锁的样子

```
powershell -ExecutionPolicy Bypass -File "Install-40HXUnlock.ps1" -Mode Uninstall -Yes
```

卸载会删掉启动项、开机任务、驱动与服务；**算力在下一次开机就回到未解锁状态**（解锁本来就是每次开机临时写的）。
有几项（GSP 开关、快速启动、目录权限）不会自动还原，卸载结束时会一条条列出来。

## 原理（想搞明白再看）

- **算力**：ESP 上的解锁固件 `\EFI\40HX\40HXUNLK.EFI` 每次开机把 SS0/SS1 写回解锁值，并预埋 4 个 PCIe Gen2 策略寄存器 + 根端口 TLS。
  它来自 **OnlyEFI v0.1.1**（`BardKing-CN/CMP40HX-Unlock-OnlyEFI`，MIT），特点：EFI 阶段**故意不重训链路**，所以不会复位显卡 → 算力与 Gen2 可以并存。
- **PCIe Gen2**：Windows 侧工具 `payload\windows\40hx-retrain-inpout.ps1` 用 `inpoutx64.sys` 直写 GPU BAR0（MMIO）+ `WinRing0x64.sys` 写 PCI 配置空间，只修两个被驱动改写的寄存器再重训根端口 → **全程不停腾讯 ACE-BOOT、不复位显卡**。
- **每次开机的自愈**：开机任务 `CMP40HX Gen2 PostBind`（SYSTEM）跑上面那套；成功率更高，驱动被杀软清了会自动从 ESP 兜底源补回；登录后 60 秒还有一次"补跑"。

**出处与致谢**：本项目基于开源项目 **CMP40HX-Unlock（https://github.com/PZH1gdmu/CMP40HX-Unlock）** 改进。
上游提供了解锁原理与 Windows 侧 helper（`CMP40HXGen2.exe` / `AutoRetrain.cmd`）与驱动思路；本包把它做成"自含、可迁移、双击即装"的一键包，
并解决了现场遇到的一堆坑：GSP（代码 43 根因）、快速启动、腾讯 ACE 预启动模式、杀软隔离驱动、目录 ACL 提权面、VBIOS 批次差异、显卡/根端口位置自动探测等。
本包**不调用**上游安装器（它会覆盖 ESP 上的 OnlyEFI 固件 → Gen2 永远落不了地），固件/启动项/任务/驱动全部自己写。

## 免责声明

- 解锁会改引导链、注册内核驱动、写固件启动项 —— **有变砖风险**（本包已尽力做备份与回滚，见 `文档\风险与恢复.md`）。
- 只对 **CMP 40HX（`10DE:1F0B`）** 做过实测；其它卡请自担风险。
- 矿卡本身可能有暗病（PCIe 延长线场景实测出现过 `0x124` WHEA 硬件错误），那与解锁无关。
- 解锁行为可能违反 NVIDIA/游戏厂商的服务条款，**请自行判断用途**（例如别拿它跑被明确禁止的场景）。
