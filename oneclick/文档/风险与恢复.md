# 风险与恢复（装/修之前先看这一页）

本包会改客户的系统。**每一项改动都有备份或回滚办法**，下面按"改了什么 / 有什么风险 / 出事怎么办"列全。
原则（也是设计约束）：

- 不删任何必要文件（驱动源改成 base64 后仍保留，随时可解回）
- **绝不复位显卡**（`HKLM\SOFTWARE\40HXUnlock` 里 `Gen2AutoHard=0` / `Gen2PnpFallback=0`，安装时无条件写）
- 不改别的软件的配置（例如七彩虹 iGame Center 的 `WinRing0_1_2_0` 服务：只避让，不动它）
- 反作弊只在必要时停下、结束就恢复；不碰、不破解反作弊
- 每个失败点都带"怎么办"提示，结束时统一打印日志路径与回滚命令

| 8 | 接管厂商遗留：禁用任务名/动作含 `40HX` 的任务、把 HKCU Run 里的 `40HXGen2` 改名成 `40HXGen2_parked` | 会影响客户自己装的厂商工具自启（但不会删） | 只禁用不删除；改名保留原值；每次开机复查并写日志 | Run 项改回来：注册表 `HKCU\...\Run` 把 `40HXGen2_parked` 改回 `40HXGen2`；任务计划里启用被禁用的任务 |

## 2. 开机任务运行时还会做的事

- 查/停/恢复 `ACE-BOOT`（腾讯反作弊预启动模式）：只在需要加载驱动的那一刻停，结束立刻按**原启动类型**恢复
- 必要时 `taskkill ACE-Tray.exe`（托盘持有 ACE-BOOT 时停不掉）→ 该次登录的托盘需要重登或由系统自启恢复
- `ThrottleStop` 退场（`sc stop` + `start= disabled`，不删文件也不删服务）
- 写日志（**2026-10-02 起「安静模式」**）：成功只往 `C:\ProgramData\CMP40HXGen2\windows\logs\postbind.log` 写 5 行判定，
  完整读数覆盖写 `logs\retrain-last.log`；`postbind.log` 超 64 KB 自动裁剪（旧内容转 `postbind.log.1`）。
  **只有失败那次**才把全量输出落盘，并另存到 `logs\failures\`（保留最近 20 次）—— 所以「没日志」不代表没跑，先看 `postbind.log` 最后一段
- 包内 `logs\` 只保留最近 10 份运行日志、`backup\` 只清理**空目录**（含内容的备份一律保留）

| 风险 | 症状 | 恢复 |
|---|---|---|
| ACE 状态不一致（客户点过"退出预启动模式"，脚本又把它恢复） | 卡在进系统界面 / 登录后没有桌面 | 双击 `工具-测试与修复\桌面恢复.cmd`（无桌面也能跑，会拉起 explorer）；或 `sc config ACE-BOOT start= disabled` + `sc stop ACE-BOOT` + `taskkill /IM ACE-Tray.exe /F`；之后在游戏客户端里点"修复/重装 ACE" |
| 托盘被结束 | 托盘图标消失 | 注销重登，或手动运行 `C:\Program Files\AntiCheatExpert\ACE-Tray.exe` |

## 4. 什么时候**不要**跑（前提，`-Mode Check` 会查）

- Secure Boot 开着 → 先到 BIOS 关（否则解锁固件不执行 / 引导改动可能被拒）
- BitLocker 开着 → 先暂停或解密（改引导链会索要恢复密钥）
- 系统盘是 MBR → 先 `mbr2gpt`（解锁固件需要 UEFI+GPT）
- BIOS 里 `Above 4G Decoding` 没开、CSM 没关、Fast Boot 没关 → 先查这三项（认不到卡 / 固件没被执行的失败里它们最常见；Above 4G 不是硬性前提，单卡主机不开也常能解锁，见 README 的 BIOS 表）
- 客户**点过** ACE 弹窗里的"退出/卸载腾讯游戏反作弊预启动模式" → 先把游戏跑一次让它自己恢复 ACE，再装本包
- 机器上还有厂商版本的 40HX 工具在跑 → 先卸载/停掉（本包会覆盖它的固件与任务）

## 5. 出事时的分级处理

1. **能进桌面**：双击 `状态自检.bat` 看结论 → 双击 `一键修复Gen2.cmd` 修 Gen2 → 还有问题跑 `-Mode Repair`
2. **黑屏/代码 43**：**完全关机**（开始菜单→关机，不是重启，最好拔电 10 秒）再开机；仍 43 就跑 `诊断包-20260930\修复-GSP.cmd` 后完全关机
3. **登录后没有桌面**：`Ctrl+Alt+Del` → 任务管理器 → 文件 → 运行新任务 → 运行 `工具-测试与修复\桌面恢复.cmd`
4. **开机不进系统**：进 BIOS 把启动项切回 `Windows Boot Manager`；仍不行就把第一启动项设成硬盘本身（本包默认不写 `bootx64.efi`；若这台主板只认它，需要加 `-WriteBootx64` 重装一次才有兜底）
5. **进不了系统 / 反复蓝屏**：开机时连按 F8（或 Shift+重启）进安全模式 → 跑 `工具-测试与修复\安全模式-修复.cmd`；实在不行用安装 U 盘启动，把 `\EFI\Microsoft\Boot\bootmgfw.efi` 覆盖到 `\EFI\Boot\bootx64.efi`
6. **彻底不要了**：`powershell -ExecutionPolicy Bypass -File <包>\Install-40HXUnlock.ps1 -Mode Uninstall -Yes`（还原引导、删启动项/任务/服务/驱动），再重启

## 6. 回滚速查

```
# 退回本次安全加固（目录权限 + 驱动源形态）
双击 工具-测试与修复\回滚-安全加固.cmd

# 主要撤销（删启动项/任务/服务/驱动；bootx64.efi 只在"曾经覆盖过"时还原）
# 注：GSP 子键 / HiberbootEnabled / 策略键 / Run 项 / 被禁任务 / 目录 ACL 不会自动还原，见下面 5.3
powershell -ExecutionPolicy Bypass -File <包>\Install-40HXUnlock.ps1 -Mode Uninstall -Yes

# 只把解锁启动项从第一位撤下来
（BIOS 里改，或 -Mode Uninstall 后重启）

# 目录 ACL 恢复成 Windows 默认（继承）
:: 让目录重新继承父目录权限（**注意**：这等于放弃本包的加固，普通用户又能替换里面的驱动）
icacls "C:\ProgramData\CMP40HXGen2" /inheritance:e /T /C
icacls "C:\ProgramData\40HXUnlock"   /inheritance:e /T /C
:: 或者直接双击 工具-测试与修复\回滚-安全加固.cmd（它只动这 4 个已知目录，更稳）
```

> 每一次 Install/Repair 的完整日志都在 `<包>\logs\run-<时间>-<模式>.log`（UTF-8），
> 开机任务的在 `C:\ProgramData\CMP40HXGen2\windows\logs\postbind.log` 与 `retrain-last.log`。
> 出问题把这几份发回来即可（别只截屏，日志里有具体退出码）。

## 7. 2026-10-01b 之后的第三方复审（DSH）与修正

本包在出包前先被隔壁 DSH 独立审查过一轮（结论"不可推送"，列了 3 条致命 + 19 条高危）。已逐条复核并处理，
连同上面的加固一起构成当前版本。**与客户安全直接相关的修正**：

- `BootOrder` 读不到时**拒绝改写**（原来会写坏引导顺序 = 开不了机），并真正备份全部 `Boot####` 原始字节。
- **默认不再覆盖** `\EFI\Boot\bootx64.efi`（改坏 = 开不了机；现在只有显式 `-WriteBootx64` 才覆盖）。
- 工具默认**不再自动写 GPU 内部寄存器**（`-AllowPrime` 才写；写前把原值落盘到 `C:\Temp\40hx-prime-backup.txt`）。
- 不再改"别的软件"的 `WinRing0_1_2_0` 服务启动类型（先校验 `binPath` 是否指向本包驱动）。
- 旧回退路径（legacy）的重训退出码不再被 `sc config` 覆盖（原来失败会被报成 PASS）。
- `Unpack-Drivers.ps1` 改为**原子写**（临时文件 + 替换），空哈希不再静默当成功。
- `一键修复Gen2` 认幂等输出（`PASS: physical Gen2 x16 reached`）、自提权会等待并传递退出码；`.cmd` 会判 `errorlevel`。
- `修复-GSP` / `一键诊断` 的"失败仍 exit 0（假成功）"已修。
- `ACE修复` 硬兜底与 `桌面恢复` 不再强行恢复"被刻意禁用（DISABLED）"的 ACE-BOOT；`桌面恢复` 改 `Winlogon\Shell` 前先把原值落档案并打印还原命令。
- `回滚-安全加固.cmd` 改成 GBK 编码（原来 UTF-8 + `chcp 936` → 中文路径乱码、根本起不来）；回滚脚本写回裸驱动时带 SHA256 校验、失败会以退出码 1 结束。
- 只读工具（判断延长线/收集蓝屏证据）在非管理员下会明确提示"读不到"，不再把"没权限"显示成"没有数据"。
- 卸载输出如实列出"不自动还原的项"（GSP/快速启动/策略键/Run 项/被禁任务/ACL），不再说"全部撤销"。
