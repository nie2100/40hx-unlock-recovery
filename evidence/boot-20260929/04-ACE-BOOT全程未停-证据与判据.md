## 怎么证明「预启动模式是在启动阶段加载的」

- boot 启动类型的驱动在系统日志里**没有** 7000/7001/7045/7036 这类事件 —— 查不到事件**不等于**没加载。
- 反作弊自己会留证据：ACE 会在安装目录写 `ace-boot-<日期>-<开机时刻>.log`。
  本机 `ace-boot-20260929-113351.log` 落到 **11:33:51**，而开机时刻是 11:33:46 → 开机后 5 秒，
  即"在启动阶段加载"成立。**若曾经被停过再拉起，这个时间就会是"拉起时刻"而不是开机时刻**，
  这也是判断"那一轮开机游戏会不会要求重启"最快的硬证据。

## 两代路径一眼区分（现场判据）

- **首选路径（2026-09-29 起）**：`postbind.log` 有 `NewPath EXIT=0` +
  `PASS: Gen2 reached on the new path - ACE-BOOT was never stopped`，且该段 0 行"已停止"
  → 腾讯游戏不会再弹"需要开启预启动模式 / 请重新安装并重启"。
- **回落路径（旧办法）**：日志出现 `NewPath EXIT=<非 0>` 或 `falling back to the legacy ...`，
  随后有"停 ACE-BOOT / 恢复 ACE-BOOT"两行 → **那一轮开机里**强制预启动模式的游戏会要求重启
  （重启一次即恢复；根治靠让新路径成功——多数情况是杀软把 `inpoutx64.sys` 隔离了，加信任区后 Repair）。
